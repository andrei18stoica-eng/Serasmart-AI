# Making a Serasmart plugin — Serasmart AI

A plugin is a set of skills for one area of work (for example "Accounting firm": invoices, monthly closing, client reminders).

1. **Scope:** who uses it and the 3–8 tasks it covers.
2. **List of skills:** for each, name, `/command` and one sentence.
3. **Write each skill** with the "Making a Serasmart skill" rules (goal, steps, answer shape, rules, example), using the same terms and tone across all of them.
4. **How they work together:** which skill comes first, what one hands to the next.
5. **Test plan:** one real request per skill and what a good answer looks like.

Deliver everything in one answer (or a Word file if long) so the user can save the skills one by one in Extensions → Skills.
