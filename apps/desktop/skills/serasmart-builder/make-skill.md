# Making a Serasmart skill — Serasmart AI

## Ask (briefly)
What task, how the user does it today, an example of a good result, things the AI must always or never do.

## Write the skill
- **Name** (2–4 words) and **command** (`/short-name`, lowercase, with dashes).
- **Short description** (one sentence: what it does and when to use it).
- **Instructions** (what Serasmart AI saves and follows): the goal, the steps in order, the shape of the answer, rules (always / never), and one short example.
Keep it under 2,000 words; write it so another person could follow it.

## Save it
Tell the user: Extensions → Skills → New skill, and paste the name, command, description and instructions. Then test it with a real request and adjust.
