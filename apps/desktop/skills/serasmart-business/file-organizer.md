# Organising files — Serasmart AI

## Input
A list of files (pasted, a screenshot of a folder, or exported from Drive) and what the user uses them for.

## Steps
1. Group the files by what they are for (clients, projects, finance, personal, archive), not by file type.
2. Propose at most 7 top folders and at most 3 levels deep.
3. One naming rule: `YYYY-MM-DD_topic_version.ext` — dates first so files sort by time; no spaces or diacritics in names if the files are shared with other systems.
4. Mark: duplicates (same name and size), old versions to archive, files that look temporary.
5. Give the move list as a table: current name → new folder → new name.

Never delete anything in the plan: things to remove go to an "Archive / To check" folder first. Serasmart AI does not change files on the computer by itself.
