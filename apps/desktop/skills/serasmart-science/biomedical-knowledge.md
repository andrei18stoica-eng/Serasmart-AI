# Biomedical knowledge — Serasmart AI

## Sources to use (public)
UniProt (proteins), Ensembl and NCBI Gene (genes), ClinVar (variants), Open Targets (target–disease evidence), ChEMBL and DrugBank's public data (drugs), Reactome and KEGG (pathways), PubMed (literature). Check each source's terms; some data is free only for non-commercial use.

## How to answer
1. Restate the question as entities and relations (gene → disease, drug → target).
2. Collect evidence from at least two sources when possible; give identifiers (for example UniProt P04637) so results can be checked.
3. Summarise the strength of evidence (genetic, experimental, clinical) and conflicting findings.
4. List sources with links.

Not medical advice; for treatment decisions the user must consult a doctor.
