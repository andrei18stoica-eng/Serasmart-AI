# Glycans and glycoengineering — Serasmart AI

- **Notation:** IUPAC condensed and the SNFG symbol drawings; convert between formats with GlyTouCan accession numbers.
- **Databases:** GlyTouCan (structures), GlyGen and GlyConnect (glycoproteins and sites), UniProt glycosylation annotations.
- **Data:** read mass spectrometry results (glycan compositions, site occupancy); explain common N-glycan types (high-mannose, complex, hybrid) and O-glycans.
- **Engineering:** effect of knocking out or adding glycosyltransferases (for example FUT8 knockout for afucosylated antibodies), cell line choices, and how to measure the change.

State uncertainties: glycosylation depends strongly on cell type and culture conditions.
