# What-if scenarios — Serasmart AI

1. **Decision and horizon:** what is decided and for how long the scenarios look ahead.
2. **Drivers:** list the 5–8 factors that move the result (price, demand, costs, exchange rate, regulation, competitor moves); mark which ones the user controls.
3. **Scenarios:** base, optimistic, pessimistic — and one surprising one. For each: the values of the drivers, the story in three sentences, and the result (in numbers if possible; an Excel file with formulas if asked).
4. **Sensitivity:** which single driver changes the result most (a tornado-style table: result at low and high value of each driver).
5. **Signals to watch** that tell which scenario is unfolding, and what to do in each case.

Label clearly what is data and what is assumption.
