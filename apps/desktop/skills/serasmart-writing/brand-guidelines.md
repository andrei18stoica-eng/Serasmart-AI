# Applying your brand — Serasmart AI

Use this to make documents, presentations, web pages or posts look and sound like the user's company. It works with the user's own brand, never with another company's.

## Collect the brand once
If the user has not given it yet, ask for (or read from an attached brand book):
- **Colours:** primary, secondary, background, text — as HEX codes (#1E3A8A). Note which colour is for titles and which for accents.
- **Fonts:** title font and body font, with a safe fallback (for example Arial, Calibri, Georgia, Times New Roman).
- **Logo rules:** where it goes, minimum size, free space around it, versions for light and dark backgrounds.
- **Voice:** three adjectives (for example clear, warm, expert), words to use and words to avoid, "tu" or "dumneavoastră" in Romanian.
Repeat the brand back as a short "Brand card" and use it for everything that follows in the chat.

## Use it
- **Documents and PDFs:** title in the title colour, headings in the primary colour, body text dark grey on white; accent colour only for highlights and table headers.
- **Slides:** one accent colour per slide, plenty of empty space, logo in the same corner on every slide, the title font for titles only.
- **Web pages:** CSS variables for every brand colour (`--brand-primary` …), contrast at least 4.5:1 for body text.
- **Texts:** follow the voice; keep sentences short; use the company's own names for its products exactly as written.

## Never
- Invent colours or fonts the user did not give: ask, or use neutral defaults and say so.
- Use the logo, colours or name of another company.
